## Project Overview
This project is developed as **Task 1** for the **CodeAlpha Java Programming Internship**. It is a console-based application designed to input, manage, and calculate student academic performances efficiently using Java standard data structures.

## Key Features
- **Dynamic Student Management:** Stores multiple student records dynamically using Java `ArrayList`.
- **Statistical Computations:** Automatically computes class average, highest score, and lowest score along with top and lowest achievers.
- **Data Validation:** Ensures score inputs are strictly within the range of 0 to 100 with exception handling for invalid numeric inputs.
- **Structured Summary Report:** Outputs a clear tabular summary of all enrolled students and aggregate metrics.

## Tech Stack
- **Language:** Java (JDK 8 or above)
- **Concepts Used:** Object-Oriented Programming (OOP), ArrayLists, Control Structures, Scanner for Input Handling
